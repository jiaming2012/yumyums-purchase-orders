# Phase 22.1 Plan 03: Migration CLI — cmd/migrate-toast-archive Summary

**Adds a standalone Go binary that walks the sales-processor local Toast archive and uploads each date's `ItemSelectionDetails.csv` to DO Spaces at `toast/YYYYMMDD/...` — idempotent (HeadObject skip), opt-in re-upload (`--overwrite`), and no DB writes. The next worker ingest tick from Plan 04+ consumes what this seeds.**

## Decisions Made

- **Env vars inline, not `LoadConfigFromEnv`:** Phase 22 D-12 makes `toast.LoadConfigFromEnv` fail-fast on missing `TOAST_SFTP_KEY_PATH`. This CLI never talks to SFTP — requiring a dummy SFTP key path for a one-shot Spaces-uploader would be hostile UX. Read the five `DO_SPACES_*` vars inline at startup; explicit list in `log.Fatal` if any are missing.
- **Sidecar is best-effort:** If `json.Marshal` of the sidecar fails OR `PutObject` on the meta key fails after a successful CSV upload, log WARN and continue. The CSV upload is the migration's deliverable; the sidecar is operational metadata. A sidecar failure should not block the whole migration.
- **`filepath.Abs` + `os.Stat` upfront:** Resolve `--source` to absolute path and stat-check it's a directory before any Spaces calls. Cheaper to fail at startup than mid-loop.
- **Regex date-dir validation also blocks path traversal (T-22.1-09):** `^\d{8}$` is a strict 8-digit match — any `..`, absolute path, or shell metacharacter fails the match and is skipped with WARN before reaching `filepath.Join`. Belt-and-suspenders alongside `filepath.Join` semantics.
- **`fmt.Println("ok")` at end:** Sends "ok" to stdout (separate from `log.Printf` which goes to stderr). Shell scripts that grep for migration success can rely on the exit code AND the literal "ok" sentinel.

## User Setup Required

Operator must set five env vars before running the CLI (same vars the receipt worker already uses, so they're already populated in `backend/.env` on the production box):

```
DO_SPACES_KEY=...
DO_SPACES_SECRET=...
DO_SPACES_ENDPOINT=https://nyc3.digitaloceanspaces.com
DO_SPACES_REGION=nyc3
DO_SPACES_BUCKET=hq.yumyums
```

Then invoke once with the absolute path to sales-processor's archive root:

```bash
cd backend
go run ./cmd/migrate-toast-archive/ --source /Users/jamal/projects/yumyums/sales-processor/output/toast_reports
# (add --overwrite to force re-upload of dates already in Spaces)
```

No DB connection required. No SFTP key required. Safe to re-run (HeadObject skip).
