**Keep verbatim — signature + lifecycle (worker.go:24-52):**
```go
func StartWorker(ctx context.Context, cfg Config) {
    interval := cfg.Interval
    if interval <= 0 {
        log.Println("toast worker: refusing to start with non-positive interval; check TOAST_SYNC_INTERVAL")
        return
    }
    log.Printf("toast worker: starting (interval=%s, window=%dd, backfill=%dd)",
        interval, cfg.SyncWindowDays, cfg.BackfillDays)
    go func() {
        runCycle(ctx, cfg)              // immediate first tick (matches receipt + purchasing)
        ticker := time.NewTicker(interval)
        defer ticker.Stop()
        for {
            select {
            case <-ctx.Done():
                log.Println("toast worker: shutting down")
                return
            case <-ticker.C:
                runCycle(ctx, cfg)
            }
        }
    }()
}
```

**Refactor `runCycle` (existing lines 56-82) to combined flow:**
- Keep `isColdStart` check and `windowDays` selection (lines 57-67) — D-02 + D-01 carry forward verbatim.
- Replace the single `RunIngest` call with a per-date loop that calls a new `syncOneDay(ctx, cfg, date)` (writes Spaces+cache) **then** continues; after the sync loop completes, call `RunIngest(ctx, cfg.Pool, cfg, fromDate, toDate)` which now reads from Spaces only.
- Wrap the Spaces interaction in a consecutive-failure counter (package-level `var consecSpacesFails int` is fine — single worker, no concurrency). On Spaces error: `consecSpacesFails++`; if `== 3`, dispatch Cliq alert via `alertQueue.Enqueue`. On success: `consecSpacesFails = 0`.

**Per-cycle log line (D-13) — keep verbatim (lines 79-81):**

```go
func uploadToSpaces(ctx context.Context, client *s3.Client, endpoint, bucket, key, filePath string) (string, error) {
    data, err := os.ReadFile(filePath)
    if err != nil {
        return "", fmt.Errorf("read file %s: %w", filePath, err)
    }
    _, err = client.PutObject(ctx, &s3.PutObjectInput{

        Key:         aws.String(key),
```

```go
import (
    "github.com/aws/aws-sdk-go-v2/aws"
    "github.com/aws/aws-sdk-go-v2/service/s3"
    s3types "github.com/aws/aws-sdk-go-v2/service/s3/types"
)

func spacesKeyExists(ctx context.Context, client *s3.Client, bucket, key string) (bool, error) {
    _, err := client.HeadObject(ctx, &s3.HeadObjectInput{
        Bucket: aws.String(bucket),
        Key:    aws.String(key),
    })
    if err != nil {
        var nf *s3types.NotFound
        if errors.As(err, &nf) {
            return false, nil
        }
        return false, err
    }
    return true, nil
}
```
