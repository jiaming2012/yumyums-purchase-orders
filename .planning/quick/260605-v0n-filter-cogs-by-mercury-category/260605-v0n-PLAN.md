<objective>
Filter COGS in `/api/v1/inventory/period-summary` by Mercury's `categoryData.name`,
so non-food card transactions (CubeSmart storage rent, fuel, supplies) stay in
`purchase_events` for bookkeeping but stop polluting the weekly food-cost numerator
sent to sales-processor.

Purpose: Eliminate operator toil of manually discarding non-food events each week,
and close the silent-mis-click failure mode that corrupts food-cost ratios.

Output:
- New migration `0065_mercury_category_on_purchase_events.sql`
- `MercuryTransaction` decodes `categoryData`; worker writes + re-syncs the column
- `PeriodSummaryHandler` filters main + `by_vendor` CTEs by configurable allowlist
- `HQ_COGS_CATEGORY_ALLOWLIST` env var (default `COGS`) wired in `main.go`
- Existing tests updated; 3 new subtests pin the filter semantics
</objective>

WITH events AS (
    SELECT id, tax
    FROM purchase_events
    WHERE event_date BETWEEN $1 AND $2
),
lines AS (
    SELECT ROUND(COALESCE(SUM(pli.quantity * pli.price), 0)::numeric, 2) AS total
    FROM purchase_line_items pli
    WHERE pli.purchase_event_id IN (SELECT id FROM events)

SELECT
    (SELECT total FROM lines)                                     AS cogs_excl_tax,
    (SELECT total FROM lines) + COALESCE(SUM(tax), 0)             AS cogs_incl_tax,
    COUNT(*)                                                      AS event_count
FROM events
```

SELECT
    v.id::text                                                                AS vendor_id,
    v.name                                                                    AS vendor_name,
    ROUND(COALESCE(SUM(pli.quantity * pli.price), 0)::numeric, 2)             AS total_excl_tax,
    ROUND(
      COALESCE(SUM(pli.quantity * pli.price), 0)::numeric
      + COALESCE(
          (SELECT SUM(pe2.tax)
             FROM purchase_events pe2
            WHERE pe2.vendor_id = v.id
              AND pe2.event_date BETWEEN $1 AND $2),
          0
        )::numeric,
      2
    )                                                                         AS total_incl_tax,
    COUNT(DISTINCT pe.id)                                                     AS trip_count
FROM purchase_events pe
JOIN vendors v                    ON v.id = pe.vendor_id
LEFT JOIN purchase_line_items pli ON pli.purchase_event_id = pe.id
WHERE pe.event_date BETWEEN $1 AND $2
GROUP BY v.id, v.name
ORDER BY total_excl_tax DESC, v.name ASC
```
