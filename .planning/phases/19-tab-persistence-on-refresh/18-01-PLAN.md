# Plan 18-01: Tab persistence on refresh via URL hash

## Goal

Persist the active tab across page refreshes for all tabbed pages using `location.hash`. When a tab is tapped, update the hash. On page load, read the hash and activate the matching tab.

## Pages to update

| Page | Tabs | Tab IDs | show() pattern |
|------|------|---------|----------------|
| workflows.html | My Checklists, Approvals, Builder | t1, t2, t3 | `onclick="show(n)"` |
| onboarding.html | My Trainings, Manager, Builder | t1, t2, t3 | `onclick="show(n)"` |
| inventory.html | Purchases, Stock, Trends, Cost, Setup | t1-t5 | `onclick="show(n)"` |
| purchasing.html | Order, Shopping, PO, History | t1-t4 | `data-action="tab" data-tab="n"` |
| users.html | Users, Edit, Access | t1-t3 | `data-action="tab-switch" data-tab="n"` |

## Implementation

### Task 1: Create shared tab hash utility

Add to each page's `show(n)` function:
```javascript
// At the end of show(n):
location.hash = 'tab=' + n;
```

Add tab restoration on page load (before or inside init):
```javascript
var hashTab = (location.hash.match(/tab=(\d+)/) || [])[1];
if (hashTab) show(+hashTab);
```

### Task 2: Update each page

For each of the 5 pages:

1. **workflows.html** — Add `location.hash = 'tab=' + n;` at the end of `show(n)`. Add hash-read in the init section. Note: workflows already uses `location.hash` for `#checklist=` — must coexist (tab hash only applies when no checklist hash).

2. **onboarding.html** — Add hash write in `show(n)`. Add hash-read after init. Note: already has `?tab=manager` query param support — hash takes precedence when present.

3. **inventory.html** — Add hash write in `show(n)`. Add hash-read on load.

4. **purchasing.html** — Add hash write in the `data-action="tab"` handler. Add hash-read on load.

5. **users.html** — Add hash write in the `data-action="tab-switch"` handler. Add hash-read on load.

### Task 3: Write regression tests

Add a test per page that:
1. Navigates to the page
2. Clicks a non-default tab
3. Verifies `location.hash` contains `tab=N`
4. Reloads the page
5. Verifies the same tab is active after reload
