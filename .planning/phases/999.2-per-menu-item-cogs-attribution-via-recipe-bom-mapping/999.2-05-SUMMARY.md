# Phase 999.2-05: Recipes Tab UI + Cross-Link Summary

**Shipped the ingredients-first Recipes tab UI (slider allocation, fullscreen picker, drift banner, read-only summary) and closed three real bugs discovered during human-verify: picker integer/date contract mismatch, Menu cards not tappable, and stale Setup tab IDs in 30+ tests + the newItem hash router.**

## Performance

- **Tasks:** 2/3 complete (initial agent), then ~3 bug-fix cycles
- **Started:** 2026-06-04 (initial agent run at ~14:09 UTC; human-verify cycles followed)
- **Completed:** 2026-06-04
- **Files modified:** 3 (inventory.html, tests/inventory.spec.js, sw.js)
- **Tests added/migrated:** 4 new + 30 migrated + 1 reload-fix
- **Final test status:** 59/62 recipes-or-setup-or-stock-related tests pass; 3 remaining failures are pre-existing (reorder data state, two PO source-string asserts) unrelated to this plan

## Accomplishments

1. **Recipes tab UI** — 7-tab layout, ingredient list sorted by last-week spend, expandable rows, 5%-snap slider with live `[%]` chip + running total, fullscreen menu-item picker that excludes already-allocated items (D-04), 422 rollback on over-allocation, drift banner (D-22), read-only menu-item summary card.

2. **Menu-tab → Recipes cross-link** (extension shipped during human-verify) — tap any menu card → switch to Recipes tab, set SELECTED_MENU_ITEM_ID, scroll summary card into view. Failing-first regression test enforces tab transition + non-placeholder card state.

3. **Picker contract guard** — `?since=90` was rejected by backend (which parses YYYY-MM-DD only) and the picker catch-block surfaced an "unavailable" alert. Failing test asserted both the backend contract (400 on `90`, 200 on `YYYY-MM-DD`) and the source-level guard (`openMenuItemPicker.toString()` must not hardcode integer since). Fix computes `Date.now() - 90d` as ISO at call time.

4. **Tab-number migration** — Plan inserted Recipes as t4, shifting Trends/Cost/Setup to t5/t6/t7. The initial agent updated tab count + 4 new tests but missed (a) 30 existing tests that still clicked `#t6` for Setup, (b) the `?newItem=` hash router in inventory.html which hardcoded `hashTab='6'` for Setup. Both fixed.
