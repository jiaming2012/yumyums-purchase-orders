## Decisions Made

- **alertSink not alertQueue.** Dispatch goes through `alertSink.Enqueue(alerts.Alert{Channel: alerts.ChannelZohoCliq, ...})` with a nil-check. The verify block explicitly asserts `! grep alertQueue.Enqueue` in scheduler.go — this guarantees the test-overridable indirection path is the only path.
- **weekStart is a string, not a time.Time.** runDriftWeek's signature is `runDriftWeek(ctx context.Context, pool *pgxpool.Pool, weekStart string)`. runDriftTick formats Chicago-local Monday with `Format("2006-01-02")` once at the boundary; tests pass `"2026-05-25"` literals. Removes a TZ-conversion class of bugs.
- **Boot-time tick.** The goroutine runs runDriftTick immediately at start so a Monday-09:00 missed because the server was restarting (deploy rollover) is recovered on first start after 09:00 — idempotency makes a re-fire a no-op.
- **Banner endpoint write pattern.** When a payload row exists, the handler writes the raw JSONB bytes back (Content-Type: application/json, body = payloadBytes). When empty, it returns `{}`. This matches D-22 self-healing — no per-user `dismissed_at` state.
- **Drift insert is unconditional within ingest-healthy weeks.** Even a clean week inserts a row with empty Sections — the banner endpoint then returns `{week_start, sections: []}` and Plan 05's frontend renders nothing. Only ingest-stale weeks SKIP the insert entirely (banner stays at the prior week's content).
