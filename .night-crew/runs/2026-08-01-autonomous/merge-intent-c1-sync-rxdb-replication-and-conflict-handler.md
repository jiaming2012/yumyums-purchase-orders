## What must survive any merge

1. **`build-sw.js`'s `vendor/**/*.bundle.js` glob and `backend/Dockerfile`'s
   `vendor/` copy are a single indivisible unit.** Either both, or neither. A
   precached URL that 404s fails the ENTIRE service-worker install for every
   returning client. The successor guard in `tests/sw-manifest.spec.js` is what
   makes "both" checkable — it must survive too.
2. **The glob form is exactly `'vendor/**/*.bundle.js'`.** Not `'vendor/**'`
   (sweeps the generator's own inputs and, absent the `vendor/node_modules/**`
   globIgnore, 8,919 files). Not `'vendor/*.bundle.js'` (silently omits a future
   `vendor/<sub>/foo.bundle.js` — fine in dev, dead offline on the truck).
3. **The conflict handler never invents last-write-wins.** No clock, no
   timestamp, participates in any decision. Decision 50 rejected genuine LWW
   explicitly. If a merge introduces a timestamp comparison into
   `sync-rxdb/conflict-handler.js`, decision 50 has been reversed by accident.
4. **A same-field clash falls back to master-wins AND is recorded.** The recorded
   clash carries the discarded fork value, so `conflict$` surfaces it recoverably.
   C2's whole design assumes this. Dropping the clash record silently restores the
   defect this card exists to fix.
5. **The `assumedMasterState`-absent fallback stays master-wins-plus-record-
   everything.** It is the decided same-field-clash branch applied to the whole
   document, not a new policy. Anything that merges optimistically without a
   baseline is inventing LWW.
6. **`workflows.html` gains import + construction only.** No `autoSaveField`
   rerouting, no `FIELD_RESPONSES` change, no `api()` change. If a merge produces
   a `workflows.html` where a user write goes through RxDB, that is
   `sync-hard-cutover` landing early and unreviewed.
7. **No client code fetches `/api/v1/sync/token`, and no client code sets
   `Authorization` or `apikey`.** The door mints per request and injects; a
   client-supplied credential is deliberately discarded. The realtime URL must
   carry **no `apikey` parameter**.
8. **`HQ_SYNC_REST_URL` is set nowhere** — no deploy, config, fixture or compose
   file. Still armed for this run.
