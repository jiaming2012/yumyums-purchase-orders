## Run mechanics

**Inherited by reference** from `.night-crew/runs/2026-07-09-attended/slate-20260710.md` → "Run mechanics" (HQ baseline gates G1–G4, G6). Not restated.

**Card-type adaptation for this slate (app-code + red-first proofs, per CLAUDE.md bug-fix protocol):**
- **G1–G2 (build/vet):** `go build ./... && go vet ./...` green in the worktree before G3.
- **G3 — Red-first proof (non-negotiable):** write the regression test FIRST; run it and **capture it failing** (the report must show the red) BEFORE the fix. Then apply the fix; run **only the new test(s)** (`npx playwright test <file> -g "<name>"` / `go test -run`) to green. A fix whose test passes without the fix (never went red) is not accepted — it doesn't guard the regression.
- **G4 — Merge-gate suite:** at merge the orchestrator runs the affected spec files + `go test` against the ephemeral env. HQ's ~37–41 pre-existing reds are the known baseline — a card is judged on its NEW test going green and introducing **no new reds**, not a globally clean suite.
- **G6 — Adversarial review:** a separate fresh subagent reviews each card against ONLY: the BACKLOG fix-card spec (cited lines), this slate entry, the diff, and the red→green evidence. It re-verifies the test genuinely went red pre-fix and the fix stayed in footprint. The roadmap row flips DRAFTING only on G6 pass.
- **Env:** per-card worktree brings up the ephemeral Docker env (`docker-compose.nc.yml`); tear down `--volumes` after. Serial → one env at a time.
- Depth reminder: **app code IS written** (unlike the last two runs). Footprint breach, an unplanned migration/lifecycle change, or an operator-only question → **PARK the card, preserve the worktree, continue.**
